# Мормышка — Android anti-stress game

Простая игра про зимнюю рыбалку: встряхивайте телефон, чтобы выполнять проводку. При достаточно ровном ритме происходит поклёвка и вибрация.

## Сборка
1. Откройте папку `Mormyshka` в Android Studio.
2. Дождитесь Gradle Sync (Android Studio скачает Gradle/плагины при необходимости).
3. Подключите Android-телефон с включённой отладкой по USB или запустите эмулятор с акселерометром.
4. Нажмите **Run**.
5. Для APK: **Build → Build APK(s)**.

Минимальная версия Android: 6.0 (API 23). Портретный режим. Игра использует акселерометр и вибрацию.
